# Changelog

## 0.1.0

### Added
- Syntax highlighting for `[lurk|...]` and `(lurk|...)` quasi-quoters
- Syntax highlighting for `[lurksql|...]` and `(lurksql|...)` quasi-quoters
- Haskell interpolation highlighting inside lurk blocks (`{{expr}}`)
- Nested injection for HTML, CSS, and JavaScript inside lurk templates
- HLS proxy for filtering hover and document highlight responses
- Dead zone detection (quasi-quote delimiters, interpolation braces)
- Snippets: `lurk`, `lurki`, `fe`, `fei`, `fmap`
- Configurable HLS path via `lurk.hlsPath` setting
